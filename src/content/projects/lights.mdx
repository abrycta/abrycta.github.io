## Problem

Official poverty estimates for the Philippines' 1,600+ cities and municipalities
come from the Philippine Statistics Authority's small-area estimates, released
every few years (2012, 2015, 2018, 2021, 2023). Between releases, and after the
latest one, there is no municipal number. Most earlier satellite-based work for
the country is cross-sectional: one map for one year.

## Approach

- **Features:** yearly statistics per city and municipality from VIIRS night-time
  lights and vegetation indices (MODIS NDVI), computed in Google Earth Engine and
  cross-checked with an independent zonal-statistics run.
- **Labels:** the PSA small-area estimates, with the standard error each one
  publishes, joined on the official geographic code. Models use the VIIRS era,
  2012–2023; the 2006 and 2009 rounds are shown as history only.
- **Model:** gradient-boosted trees (LightGBM) predicting the change since the
  last PSA round, compared with carrying the last official value forward in
  forward-chaining backtests. It builds on
  [a paper I co-authored](https://link.springer.com/chapter/10.1007/978-3-032-23515-2_43), which used a recurrent network (GRU). Training runs
  offline in GitHub Actions; the Rust core reproduces the trained model's
  predictions exactly (largest difference 3.7 × 10⁻¹⁴).
- **Intervals:** 50 % and 90 % ranges from split-conformal calibration on rounds
  the model had not seen.
- **In the browser:** the same Rust core, compiled to WebAssembly, recomputes a
  municipality instantly for "what if" sliders, which are labelled as hypothetical.
- **Uncertainty first:** official estimates are shown with their intervals beside
  the model and its backtest error. The few labelled years per municipality and the
  2018 methodology change are stated, not hidden.
- **Languages:** English and Japanese, with captions first.

Paper: M. C. Clemente, J. Dela Cruz, K. R. Mendoza, K. M. Nudo, et al.,
["Temporal Analysis of Nighttime Lights and Vegetation Indices for Poverty
Forecasting: A Recurrent Neural Network Perspective"](https://link.springer.com/chapter/10.1007/978-3-032-23515-2_43), in _Machine and
Computing Technologies for Sustainable Development_, Lecture Notes in Networks
and Systems, Springer, 2026, pp. 451–461.

## Architecture

Standard pattern: a hexagonal (ports and adapters) core with materialised read
models, delivered as a static Jamstack site. Customisations: one Rust core with
three driving adapters (a command-line tool in GitHub Actions, WebAssembly in the
browser, and later a Rust API under `/api/` on the same site), so every number
is computed by the same code; the map tiles and per-municipality files are
prebuilt and served as static files from Cloudflare Pages.

## Where it stands

Live at [lights.krtmtthw.dev](https://lights.krtmtthw.dev) since 2026-10-21: a map of
every city and municipality for 2012–2025 with a detail panel, a chart, and a
"what if" that runs in the browser, in English and Japanese. The data is
processed in GitHub Actions, about 17 minutes per full run.

Results, scored on PSA's published estimates (n ≈ 1,600 per round):

- **2023 nowcast:** average error 5.6 percentage points against 6.3 for carrying
  the 2021 value forward (12 % lower), and the 90 % ranges contained 95 % of the
  official figures.
- **Satellites add little:** removing every satellite feature raises the 2023
  error by only 0.05 points. The gain comes from PSA's own history, which matches
  the paper.
- **Weaker years:** across PSA's 2018 method change the model does worse than
  carrying the last value forward, and with only one or two training rounds its
  90 % ranges hold 65–69 % of the figures.

So most model estimates are marked "unreliable" on the map, drawn lighter and
always beside PSA's official figure. Still to come: the API.

Known limitations: only a few labelled years per municipality (2012, 2015, 2018,
2021, 2023); PSA changed its method in 2018 and some boundaries have changed
since, so years are not strictly comparable; the 14 City of Manila districts and
highly urbanised cities have no PSA small-area figure, so they show model
estimates only.
