## Problem

Every project here is a data-heavy app: maps, small multiples, tables of numbers,
and text that may be Japanese or English. Starting each one from a generic
component library meant re-deciding colour scales, Japanese typography, focus
styles and dark mode every time, and contrast came out wrong in at least one theme.

## Approach

- **Tokens first:** colours, type, space, radius and motion are written once, as
  [DTCG](https://www.designtokens.org/) design tokens. The tokens come in three tiers
  (primitive, semantic, component) and four themes: light, dark, and a high-contrast variant of each.
- **Generated, not hand-copied:** a build step turns the tokens into CSS variables,
  a Tailwind v4 theme, the shadcn/ui variable mapping and typed TypeScript exports.
- **Components:** the full shadcn/ui set, left unmodified so upstream updates apply
  cleanly. Akari adds a few pieces of its own: seal mark, stat card, sparkline, map legend,
  language switch and theme toggle.
- **Checked:** contrast tests cover every promised text and UI pair in all four
  themes. Storybook stories also run through visual and accessibility tests.
- **Maps:** MapLibre style helpers use the same palette as the charts.

This site is built with it; see the [living showcase](/akari/).

## Architecture

Standard pattern: a token-driven design system, where design tokens are the
single source and a build generates each platform's format, with a component
kit on top. Customisations: tokens follow the DTCG 2025.10 format. The shadcn/ui
components stay as upstream source, synced weekly, with Akari's changes kept
as marked hunks. One package
serves React apps, plain CSS pages and Tailwind apps alike.

## Where it stands

Akari is still growing. Every app on krtmtthw.dev shares one menu bar and
breadcrumb, and the apps pass in data only. Version 0.8.0 made the bar's glass more
see-through while keeping all its text at 4.5:1 or more over any content. The same
release added an Auto / Light / Dark theme button shared across the apps, and helpers
for showing uncertainty: map hatching for less reliable values, ranges on small
charts, an "official vs model estimate" badge, and a scroll-driven story layout.
A full-width page layout followed in 0.9.0, lined up with the full-width bar. Later
releases brought dated event markers on charts, a compact layout rhythm by default,
one legible map palette in all four themes, and GitHub and LinkedIn icon links in
the menu bar. In 0.19.0 came layout tokens, such as the menu bar's height, and an
eyebrow label component. Versions 0.20.0 and 0.20.1 spaced the menu bar's icon
buttons apart, gave the automatic theme its own sun-and-moon icon, and let phones
show a shorter tagline in the bar. Replay, Lights, Plumes and this site all run on
0.20. The source is private, but the projects above and the
[living showcase](/akari/) show it in use.

Nearly all of the package's roughly 12 MB is the Japanese Mincho font, and browsers fetch only
the slices a page uses.
