## Problem

Every project here is a data-heavy app (maps, small multiples, tables) with text in
Japanese or English. A generic component library meant re-deciding colour scales,
Japanese typography, focus styles and dark mode each time, and contrast broke in at
least one theme.

## Approach

- **Tokens first:** colours, type, space, radius and motion are written once as
  [DTCG](https://www.designtokens.org/) design tokens, in three tiers (primitive,
  semantic, component) and four themes: light, dark and a high-contrast version of each.
- **Generated, not hand-copied:** a build turns the tokens into CSS variables,
  a Tailwind v4 theme, the shadcn/ui variable mapping and typed TypeScript exports.
- **Components:** the full shadcn/ui set, unmodified so upstream updates apply cleanly,
  plus Akari's own seal mark, stat card, sparkline, map legend, language switch and
  theme toggle.
- **Checked:** contrast tests cover every promised text and UI pair in all four
  themes. Storybook stories also run through visual and accessibility tests.
- **Maps:** MapLibre style helpers use the same palette as the charts.

## Architecture

Standard pattern: a token-driven design system, where design tokens are the
single source and a build generates each platform's format, with a component
kit on top. Customisations: tokens follow the DTCG 2025.10 format. The shadcn/ui
components stay as upstream source, synced weekly, with Akari's changes kept
as marked hunks. One package
serves React apps, plain CSS pages and Tailwind apps alike.

## Where it stands

Replay, Lights, Plumes and this site all run on 0.20. Every app on krtmtthw.dev
shares one menu bar and breadcrumb, and the apps pass in data only. The bar's glass
keeps all its text at 4.5:1 or more over any content, and one Auto / Light / Dark
theme button is shared across the apps. Helpers show uncertainty: map hatching for
less reliable values, ranges on small charts, an "official vs model estimate" badge
and a scroll-driven story layout. The projects above and the
[living showcase](/akari/) show it in use.
